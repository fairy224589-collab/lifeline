LIFELINE CONSOLIDATED DEMO UPGRADE

WHAT IS INCLUDED
- Existing LifeLine homepage and original visual components preserved.
- Existing donor, hospital, blood bank and login routes preserved.
- Rapid Blood Finder now creates a unique demo Blood Unit ID.
- Each reservation creates a linked Unit Passport and a demo request record.
- Unit Passport registry with status progression and browser persistence.
- Admin Control Room at /admin with Overview, Requests, Donors, Inventory and Passports tabs.
- Notifications centre at /notifications.
- Main navigation links to Blood Bank, Unit Passport and Control Room.
- Demo events generated by Rapid Finder appear in Notifications and Control Room.

IMPORTANT
This is a student demonstration prototype. Sample donors, inventory, requests, unit IDs,
notifications, distances and statuses are fictional. Browser storage is local to this browser
and is not synced across users or devices. This is not a real blood-bank, clinical matching,
reservation, dispatch, or medical traceability system.

INSTALLATION
1. BACK UP your current lifeline folder first.
2. Extract this archive. It contains the project source folder named lifeline.
3. Copy the source folders/files into your existing project folder, allowing code files to be
   replaced. Keep your existing .env.local file; it is intentionally NOT included here.
4. Do not copy node_modules from another machine. Keep your current node_modules if present.
5. In PowerShell, open the project folder and run:
      npm.cmd install
      npm.cmd run dev
6. Visit http://localhost:3000

NEW PAGES
